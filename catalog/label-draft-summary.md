# 68 条旧 demo 样本的匹配诊断

**性质：AI 辅助草稿与当前规则的对照，不是经过真人复核的 precision / recall。** 样本来自旧 demo 的 15 个 HTTP 测试记录，按来源原生 ID 去重；测试查询偏向少数热门卡，且当前规则已参考样本中的失败形态调整，不能当作盲测。

| 口径 | 结果 |
| --- | ---: |
| 去重 listing | 68 |
| 可提出卡组＋卡号候选 | 40 |
| 候选身份已进入本期日文目录 | 34 / 40 |
| 目录内候选获标题规则自动接纳 | 28 / 34 |
| 自动接纳与 AI 身份草稿一致 | 28 / 28 |
| 14 条应弃权样本被自动接纳 | 0 / 14 |
| 22 条标题有评级声明，且被自动接纳 | 13 / 22；13 条与草稿机构／分数一致 |
| 有独立证据的卡组＋卡号＋版本完整标签 | **0** |

未进入目录的 6 条身份候选全部属于 **S6a**。已在目录内却未自动接纳的 6 条，标题缺卡组代码或卡号；规则保守弃权。`holo`、`normal` 等曾从稀有度推断的草稿版本已撤回，故**目前无法测版本匹配精度**。本诊断的逐 listing 记录留在私有工作区，不随目录交付。

下一轮需用已授权 listing 的卡面图，让两位真人独立标注并裁决版本；详见 `labeling-protocol.md`。随后冻结 matcher 和目录版本，在独立盲测样本上分别报告身份、版本与评级精度。
