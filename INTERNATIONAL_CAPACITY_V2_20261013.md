Each Docker build creates a typed static read-model artifact after finalizing its own catalogue database. The artifact binds actual database bytes, the manifest, complete runtime policy files, native schema and engine/Unicode profile, and the independently derived native conversation revision. It stores effective facets, fixed vocabularies, current source-evidence membership, reviewed affiliation proofs and bounded matching facts. It contains no user session, text, query result, ranking, inventory, market data or permission grant. The four documented generated timestamps may change legitimate rebuild bytes; each build receives its own artifact while the existing independent full logical digests retain their original normalization rules.

The reviewed image requires the artifact at fixed packaged paths before listening. A present invalid or partial artifact fails startup. Generic diagnostic bootstrap can explicitly use the native path only when the optional package is wholly absent. Offline/custom loading requires the original, separately trusted seal digest. Adjacent self-hashes do not authenticate a producer; fixed-image trust rests on the immutable image and independent full native-state verification.
